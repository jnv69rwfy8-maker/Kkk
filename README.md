# رُكن — Personal Utility Hub (v10)

**النشر:** ارفع كل الملفات في جذر مستودع GitHub Pages (index.html, sw.js, manifest.json, الأيقونات, favicon, logo.svg).
**البيانات:** مفتاح التخزين `jlos` لم يتغيّر، والتحديث لا يمسح أي بيانات. كاش الخدمة: `personal-utility-hub-v10-rokn`.

## الهوية
- لونان أساسيان: فيروزي (tq-900…100) وقرمزي (cr-700…100)، مع لوحة كاملة للفاتح والداكن (خلفيات، أسطح، حدود، نصوص، نجاح/تحذير/خطأ/معطّل) كمتغيرات CSS في أول ملف الأنماط.
- الشعار: شعار «رُكن» المرفق، محوَّل إلى SVG نظيف (logo.svg) وأيقونات PWA/iOS/favicon منه، ويظهر في رأس التطبيق على بلاطة بلون الخلفية الأصلية.
- التصميم: رموز (tokens) للمسافات والزوايا والظلال والحركة وأحجام الخط. الخط: خط النظام (يعمل بدون إنترنت)؛ لإضافة خط خاص ضع ملف woff2 وعرّفه في `@font-face "Sans AR"`.

## المترو (تدقيق وإصلاح)
المشكلات التي وُجدت وأُصلحت:
1. في الخط الثاني كانت المحطة «ضواحي الجيزة» مكان «أم المصريين» (20 محطة صحيحة). صُححت بناءً على معرفتي بالخريطة الرسمية، **ويُفضّل مطابقتها مع خريطة المترو الرسمية**. تُحوَّل المحطة المحفوظة قديمًا تلقائيًا.
2. الانتقال بين فرعي الخط الثالث (روض الفرج وجامعة القاهرة) كان يُحسب كأنه قطار واحد؛ صار «تغيير القطار في الكيت كات».
3. حساب أفضل مسار كان يستخدم إعدادات قديمة (دقائق) بدل إعدادات الثواني الحالية.
4. عرض النتيجة لا يوضّح الخط والاتجاه؛ صار مقسّمًا إلى مراحل بلون الخط واتجاهه وعدد محطاته مع رابط Google Maps.
المراجعة: محطات التبديل المعتمدة 5 فقط (السادات، الشهداء، العتبة، جمال عبد الناصر، جامعة القاهرة). التوقيت تقديري ومبني على أزمنة قابلة للتعديل بالثواني، ولا توجد بيانات حية أو أسعار أو مواعيد تشغيل.

- أُصلح خطأ في النسخ السابقة كان يستبدل كلمة Cairo داخل أسماء بعض الأماكن.

## تقني
- بحث شامل من الهيدر (أماكن + محطات)، إجراءات سريعة في الرئيسية، دعم تقليل الحركة، رمز لون المتصفح يتبع المظهر.
- لا يوجد شاشة بداية iOS (تحتاج صورًا بأحجام كثيرة).
